## ตัวกรองในเกม (v1.33)

แท็บ **WEAPON → Weapon Spawner**:

- `เฉพาะปืนที่เซิร์ฟเวอร์มี (owned)` — เหลือเฉพาะ id ที่อยู่ใน
  `pb.respawnMenu.sel.allItems` และผ่าน `allowedId` ของ slot นั้น
- `เฉพาะปืนที่ดาเมจ > 0` — ซ่อนไอเทมที่ดาเมจ 0 (ยกเว้นมีด/ระเบิด)
- ช่องค้นหา + ตัวกรอง slot ยังใช้ร่วมกันได้

## ดึงรายการจริงของ match/บัญชีคุณ

แท็บ **SAFETY → Server Check**:

- `CHECK` — ดู `weaponsFlag`, `ack loadout`, จำนวน inventory และรายการต่อ slot
- `COPY ALLOWED` — คัดลอก CSV ของปืนที่ **server ยอมรับใน match นี้**
  (คอลัมน์ `slot,id,name,damage`)
- `COPY DB` — คัดลอก CSV ของปืนทั้งหมดที่ผ่านตัวกรองดาเมจ
  (คอลัมน์ `slot,id,name,family,damage`)

CSV ที่ได้เอาไปเปิดใน Excel/Sheets ได้เลย

## “ทั้งหมด” = ทั้งคลังแสง ไม่ต้องเทสทีละกระบอก

`Server Owner` คือรายการในคลังแสงของเกม (`ws.db.all()` → `weapons.json`)
ที่กรองเอาเฉพาะกระบอกที่ใช้งานได้ (ดาเมจ > 0 หรือมีด/ระเบิด, ไม่รวม `Equipment`)

รายการนี้คือตารางเดียวกับที่ host ใช้คิดดาเมจ ดังนั้นกระบอกที่ไม่มีขายในร้านค้า
แต่มีอยู่ในคลังแสงก็ยิงได้ — ไม่ต้องไล่เทสทีละกระบอก

ป้ายในหน้า Server Owner:

| ป้าย | หมายถึง |
|---|---|
| **มีแล้ว** | ID อยู่ใน inventory ที่ server ส่งมาให้บัญชีคุณ (`sel.allItems`) |

การใช้งาน:
1. เปิด `ปืนที่มีแล้ว: sync + ไม่ใช้ proxy`
2. เสกปืนที่ต้องการ
3. **ตาย/เกิดใหม่ 1 ครั้ง** เพื่อให้ server ack loadout
4. หลังเกิดใหม่ ปืนจะยิงด้วยดาเมจปกติโดยไม่ต้อง proxy

> การ equip กลางชีวิตจะยังไม่ถูก ack — แม้ปืนจะอยู่ในคลังแสงก็อาจดูเหมือนถือ
> แต่ยิงไม่เข้า จนกว่าจะ respawn หนึ่งครั้ง

## `[loadout] the server's RESPAWN differs ...` คืออะไร

ข้อความนี้มาจากฟังก์ชัน `adoptServerLoadout()` ของเกมเอง:

```text
[loadout] the server's RESPAWN differs from the equipped loadout:
primary 106246 -> 106001 (the match host accepts the server's items only)
```

แปลว่า host รับเฉพาะไอเท็มที่ **server ส่งมาใน respawn inventory** เท่านั้น
ถ้าคุณเสกกระบอกที่ไม่อยู่ในลิสต์นั้น เกมจะ equip กระบอกของ server ทับ
(ในตัวอย่างคือกลับไปเป็น 106001)

สิ่งที่ esp.js v1.44 ทำ:

- เปิด `คงปืนที่เสกหลังเกิดใหม่ (proxy อัตโนมัติ)` (default)
- เมื่อ `adoptServerLoadout()` ทำงาน → ติดตั้งกระบอกที่เสกกลับให้ทันที
- ตอนยิง → ส่ง ID ที่ server รู้จัก (proxy) เพื่อให้ host คิดดาเมจ
- ไม่ต้อง pickup และไม่ต้องกดอะไรซ้ำหลังเกิดใหม่

ข้อจำกัด: ดาเมจจะถูกคิดตามกระบอกที่ server รู้จัก (proxy id)
ไม่ใช่ค่าดาเมจของกระบอกที่เสก — แต่ยังเป็นการ “ยิงแล้วตาย” ปกติ

ถ้าปิด `spawnProxy` กระบอกที่ไม่อยู่ใน respawn inventory จะยิงไม่เข้า

## ทำไม static scan บอก “server เปิดอะไร” ไม่ได้

`respawnInventory` ถูกส่งจาก server ตอนเข้า match และขึ้นกับบัญชี/ห้อง/โหมด
จึงไม่มีอยู่ใน bundle ของเว็บ และไม่มี endpoint public ให้ดึงโดยไม่ล็อกอิน
สิ่งที่ client รู้ได้คือค่าที่ server ส่งมาใน `pb.respawnMenu.sel` และ `net.localLoadout`
เท่านั้น — ตัว `COPY ALLOWED` คือคำตอบที่ตรงที่สุดสำหรับ match ปัจจุบัน
